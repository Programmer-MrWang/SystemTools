# M5 逐批实现与验证

日期：2026-11-15。主线 `codex/cross-platform`，正式开发目录 `C:\STWork-Windows\SystemTools`。

执行顺序按 M5 计划：能力/资源 → 相机 → 听写 → 唤醒 → 对话/打断 → 认证 → 媒体 → 三端集成。Windows 原 ID、设置、密文及 AI 工具审批保持兼容，原有 IDE 和未提交进度报告保留。

## M5.0 媒体契约与资源边界

增加窄接口：相机、流式识别、系统认证、媒体会话；平台媒体服务持有停止令牌，停止回调失败仍继续释放资源，同一实例只释放一次。设备所有权不在取消时提前释放，必须等待采集退出，避免旧任务与新任务同时访问设备。

相机输出使用唯一临时文件，检查 PNG 后提交；失败和取消清理临时文件。显式错误的依赖路径不会回退到其他可执行文件。公共合成测试覆盖并发占用、取消、幂等释放、停止容错和坏图片清理，Windows 执行通过。后续逐批追加真实设备和平台运行结果，不将接口实现记为桌面成功。

## M5.1 摄像头单次抓拍

保持 CameraCapture 行动 ID、deviceName/saveFolder 字段和设置页身份，将行动链接到共享层。改为参数列表启动采集，添加设备核对、设备互斥、20 秒超时、行动中断/插件停止取消和唯一临时 PNG 提交；不再拼接命令字符串或直接写最终文件。

Windows 本机指定 ASUS FHD webcam 实际连续抓拍两次通过，输出文件不冲突；未知设备拒绝且无半成品，预取消不进入采集。包含公共保护的 13 项检查通过。Mac 使用 AVFoundation 原生照片输出和显式权限请求，Linux 使用 V4L2/FFmpeg；三平台托管编译通过。Mac 原生桥接需要原生 CI 编译，真实权限与照片成功路径需对应 Mac；Linux 摄像头实机同样独立列出。

宿主仅补相机和麦克风用途声明，两项 plist 解析校验通过；Windows 宿主带既有 SourceLink 本地参数构建成功。未在 Windows 声称验证 Mac 摄像头或权限归属。

## M5.2 语音、关键词与对话

增加 16 kHz PCM/Vosk 流式后端：Mac AVAudioEngine 在专用串行队列启动/停止，转换后的缓冲有上限；Linux FFmpeg/PulseAudio 子进程在取消后终止并等待退出；Windows 复用既有 Worker，不建立第二套录音引擎。通过显式 Media.json 模型配置使用原始本地 Vosk 模型，自动发现的旧模型仍保留原认证规则。

麦克风路由器在切换前台听写/对话时先取消并等待后台关键词采集结束，前台退出后恢复后台；对话代次拒绝迟到回复，打断取消生成和当前独立朗读进程。原有行动/档案 AI 工具及本地确认继续复用，取消或关闭确认窗口不放行。Mac/Linux 增加共享文字/语音对话入口和仅内存 API 密钥，不写明文密钥，不擦除旧 DPAPI 密文。

Windows 公共检查 184 项及 M5 合成状态机/资源/歌词检查 22 项通过。官方 Vosk 英文音频夹具由真实模型解码，包含预期 one/zero 内容。隔离 Windows 宿主候选包实际加载模型、打开默认麦克风、收到 24 条真实 PCM 音量事件，停止确认及预取消通过，未保存日常录音。

## M5.3 系统认证

Windows Hello 原实现和原身份保留；实际只读检查本机为 Available，无窗口句柄时明确拒绝放行。真实人脸/PIN 成功和人工取消需要用户本人在系统窗口参与，不能以只读探测冒充成功。Mac LocalAuthentication 后端使用独立上下文，取消使上下文失效并拒绝迟到成功；新增系统认证身份不冒充 Windows Hello。Linux 按计划保持不支持并始终拒绝放行。

宿主相机/麦克风用途声明本地提交 e7d8f874；官方仓库推送被 403 拒绝，补丁已保存至 eng/host-patches/classisland-m5-media-permissions.patch，插件仓库可携带接手。没有改动远程权限或擅自重设宿主远程。

## M5.4 媒体与歌词

Windows 通过 SMTC 读取会话；Linux 使用当前用户 D-Bus/playerctl 并读取真实进度，Mac 通用媒体状态按计划保持不支持。共享后台监测在失败/停止时清空状态，Windows 规则不再在错误后保留过期的播放成功。Windows 合成静音媒体播放器实际完成 Playing→Paused 的系统会话验证，没有操作用户播放器。

Windows 原歌词窗口捕获保留，修复替换/清空/卸载时的 Bitmap 释放。Linux 在用户显式提供当前曲目 LRC 文件且真实进度可用时显示对应歌词；没有文件、真实进度或会话时不虚构歌词。LRC 时间、偏移和多标签定位的合成检查通过。

本批代码已完成 Windows 编译和当前候选包本机验收；原生三端 CI、最终同源包及完整 Windows 三场景仍在 M5.5 继续，不能把候选包当成最终三端包。
