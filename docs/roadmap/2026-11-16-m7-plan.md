# M7：统一候选版与发行工具

基线 9c9c0ad；分支 codex/cross-platform；SDK 精确 10.0.403。用户确认暂时没有 Apple Developer Program 正式签名条件，本轮完成候选版、发行工具和本机可取得的证据；正式签名、公证与公开发行保持门禁，不伪装为已完成。

每批按实现、相关检查、自审、中文约定式提交、代理推送的顺序进行。ClassIsland 源码和安装应用不变，原有 dirty 和迁移纠正保留。

| 顺序 | 交付 | 完成条件 |
| --- | --- | --- |
| M7.0 | 冻结身份、候选版本、支持矩阵及验收门槛 | 统一配置、版本和发布状态；保存接手保护基线 |
| M7.1 | 依赖、安全、许可证和包审计 | 实际解决发布依赖安全公告；版本/架构/重名冲突检查；产物依赖清单和许可证来源 |
| M7.2 | 冲突防护、旧版迁移、回退与卸载工具 | 显式计划、备份、幂等、未知字段/密文/附件保留、退出宿主、条件回滚、旧包停用 |
| M7.3 | Mac 签名/公证发行链 | 可执行 dry-run/preflight/sign/notarize/verify；候选包标明 ad-hoc，缺正式凭据时拒绝 stable |
| M7.4 | 同源三端候选版与能力文档生成 | 同版本/提交/SDK/公共输出，台账 ID 与生成的平台表一致，可选依赖不冒充核心 |
| M7.5 | 安装生命周期与最终候选包验收 | Mac 新装/升级/重启/停用/异常恢复/卸载；旧包与回退有绑定证据；三端构建不替代实体设备 |
| M7.6 | 文档和接手收尾 | 发布说明、已知限制、回退操作、发布门禁报告、原维护分支/基线保留 |

候选版本使用 SystemTools 正式身份和 3.0.0.0 数字版本，发布渠道为 rc；不创建公开发行或市场条目。目标是现有 Avalonia/API 2.2 宿主线，实际已验收宿主为未修改的 ClassIsland Misha 开发版（显示版本 2.1.1.1）；不将其描述为所有官方稳定版已验收。
