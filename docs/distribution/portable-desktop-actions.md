# 新增桌面行动的跨平台语义

稳定 ID 和原设置字段保持。Mac 的 AltF4、AltTab、CtrlZ 分别映射为 Command+W、Command+Tab、Command+Z；这是关闭当前窗口、切换应用和撤销的系统语义。键入内容使用目标窗口 Unicode 输入，不占用剪贴板。目标改变时停止后续输入，取消时释放已按下的键。

鼠标坐标是当前平台桌面逻辑坐标，显示排列、Retina/DPI 或系统切换后需要重新记录。设置提供逐步编辑；旧 disableMouseDuringExecution=true 会明确拒绝，需本人关闭，插件不模拟禁用物理鼠标。

计时关机由插件保存内存计划，退出宿主、取消/回退行动会取消未派发计划；不向系统建立宿主退出后仍继续的关机任务。取消仅取消本插件计划，不撤销其他程序的系统计划。高级计划可查看剩余时间、延长和取消。系统请求派发后仍受系统授权与关机流程控制，不能保证撤回已交给系统的操作。自动检查不执行真实关机、重启、睡眠或锁屏。

Mac 的电源/锁屏及系统浅深色通过自有 Companion 的白名单 AppleScript 请求 System Events，助手拥有用途声明和自动化 entitlement；原版宿主不修改。系统可能请求自动化或辅助功能授权，拒绝会显示失败。系统主题会读回确认，回退只在当前值仍为本插件设置时恢复，保留用户后续手动修改。Mac 通用显示桌面和任意系统强调色没有本插件已验证的可靠公开写入接口，仍明确不可用。

Linux 电源由 systemd-logind 能力探测和 systemctl 当前用户授权执行，不 sudo 整个 GUI；锁屏为 loginctl 当前会话，显示桌面使用 X11/EWMH wmctrl。系统主题和强调色仅在实际 GNOME schema 可用时开放；强调色采用 GNOME 固定色板，旧任意颜色选择最接近系统色并在设置明确说明，KDE/其他桌面保持不可用而不写私有配置。

主界面点击使用实际 Avalonia 输入；鼠标穿透时没有点击事件，不冒充全局钩子。黑屏为自有全屏窗口，Esc 或单击退出，宿主退出会关闭。行动流确认沿用原对话/延后/停止设置。背景音频支持中文路径、等待/后台及停止释放。
