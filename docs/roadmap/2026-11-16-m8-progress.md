# M8 逐批自审记录

## 1：共享交互与媒体行动

复用原行动流确认与设置，接入两项触发器；背景音频支持中文路径、等待或后台、取消和宿主停止；黑屏使用自有可退出全屏窗口，不通过浏览器抢发 F11。主界面触发器使用 Avalonia 输入事件，在穿透模式下明确不触发，未冒充 Windows 全局鼠标钩子。

Release 编译与 121 项共享回归通过。自审修正新行动菜单重复和后台播放取消/释放竞争；新增窗口由宿主停止生命周期统一关闭。实际 UI/音频及取消行为会在最终 Mac 探针中验证，当前编译不作人工交互证据。

## 2：Mac Keychain 与 Linux Secret Service

接入独立凭据后端和明确的保存/移除按钮。Mac 使用系统 Generic Password；Linux 经 secret-tool 标准输入保存、随机属性定位，要求当前用户 D-Bus/密钥环。配置仅保存引用，错误拒绝时保留原密文与会话路径。

本机 12 项原生凭据检查通过，用户本人允许系统钥匙串弹窗；包括跨进程重新读取、合成项目删除及删除后拒绝。后续新增 2 项配置写入冲突保护，总计 7 项凭据契约与 121 项共享回归通过。自审修正“配置保存失败但先删除旧密钥”的风险，失败恢复内存并清理本次新项目；历史系统项目保留供旧配置回退。正式宿主与 Linux 实际服务仍须单独验收，未把 dotnet 授权冒充宿主证据。

## 3：平台输入、电源与系统外观

新增 Mac Quartz/Linux XTest 鼠标、逻辑快捷键及 Unicode 键入、精确进程名退出；计时关机共享取消状态机、自有高级倒计时窗口，宿主停止取消待执行计划。Mac 系统请求经自有助手白名单 AppleScript，新增助手自动化用途与 entitlement；Linux 使用 logind/systemctl、X11/EWMH 和实际 GNOME schema。Mac 显示桌面/任意系统强调色、其他 Linux 桌面的系统外观保持明确边界。

Release 构建通过，13 项新增凭据/计划/输入契约和完整既有 M7 回归通过。自审改进取消时鼠标释放、失败反馈、中文路径和设置可编辑性，避免将 JSON 编辑器作为普通鼠标步骤界面。没有自动执行真实电源操作；Mac 实际输入/自动化授权和 Linux 桌面仍需后续探针。平台表同步由同一台账生成。
