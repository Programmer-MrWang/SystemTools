## 数据台账

| 数据 | 当前归属 | M3 规则 |
| --- | --- | --- |
| Main.json 与 .bak | 插件配置目录 | 保留字段名、默认值、启用字典、密文和未知嵌套字段 |
| FloatingWindowProfiles/*.json | 旧依赖缓存根 | 迁到插件配置目录，原文件保留；冲突不覆盖 |
| AiConversations.json、附件引用 | 插件配置目录 | 原 ID、会话顺序、附件路径和未知字段保留 |
| 工作流、触发器、规则 | 宿主自动化配置 | 只对明确身份字段作映射，不替换用户文本 |
| 组件、主题、授权器 | 宿主对应配置 | 显式 GUID/ID 映射；授权要求不降级 |
| 模型、原生依赖、下载文件 | 插件依赖缓存 | 不当成用户配置迁移或自动删除 |

迁移工具先生成预览，目标已有不同内容时必须显式选择。默认不写宿主或真实用户目录；测试和验收使用 artifacts 下隔离目录。旧版与新版不得同时注册相同 ID。

M2 真实麦克风/模型、相机、Windows Hello、SAI、系统硬件操作与正式升级验收继续独立追踪，不以 M3 构建通过替代。
