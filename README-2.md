## SystemTools v3.0.0.0（Hoshimi Miyabi） - 2026.8.13更新

> [!WARNING]
> - 本版本插件清单要求的 ClassIsland 插件 API 由 **2.0.0.0** 升级为 **2.2.0.0**，项目运行目标由 **.NET 8 / Windows 10.0.17763** 升级为 **.NET 10 / Windows 10.0.19041**。升级插件前请先确认 ClassIsland 版本满足新的插件 API 要求。
> - AI 功能需要自行配置兼容 OpenAI API 格式的服务地址、API Key 与模型。AI 语音功能还需要下载 VoskWorker 和一个经 SystemTools 认证的语音识别模型。
> - **Windows Hello 验证器** 仅支持 Windows 11（内部版本 22000 及以上），并要求当前 Windows 用户已录入 Windows Hello 人脸；系统验证界面可能根据设备配置回退到指纹或 PIN。

> [!NOTE]
> 经 2.5.1.0 与 3.0.0.0 两个版本的实际注册代码对照，本版本没有新增普通组件和规则集。新增内容主要集中在 AI、语音、触发器、行动、悬浮窗、验证器、主题和系统辅助功能。

### 🚀 新增：

- **[AI 功能/设置页面]**: 新增 **AI 对话** 功能和独立设置页面
  > 支持配置兼容 OpenAI API 格式的供应商名称、API Key、API 请求地址和默认模型，并可从服务端读取模型列表
  >
  > 支持流式回复、多段对话记录、新建/切换/重命名/删除对话、编辑用户消息后重新生成，以及重新生成已有 AI 回复
  >
  > 支持将对话记录保存到本地，并可选择把 AI 回复共享到 ClassIsland 通知
  >
  > 位于 *[ SystemTools 设置 > 主设置 > AI 服务 ]* 和 *[ SystemTools 设置 > AI 对话 ]*

- **[AI 功能]**: 新增 **文档与图片附件**
  > 支持选择或拖入图片、PDF 和文本类文件，也支持直接粘贴剪切板图片
  >
  > 图片格式包括 PNG、JPG、JPEG、WebP、GIF；文本类附件包括 TXT、Markdown、JSON、XML、YAML 等格式
  >
  > 添加附件时会检查文件类型、单文件大小、附件数量和待发送附件总大小，并在拖放后显示确认结果

- **[AI 功能]**: 新增 AI 读取与修改 **ClassIsland 档案/课表** 的能力
  > AI 可读取当前档案中的时间表、课表、课程、科目、任课教师、课表群和预定课表等数据
  >
  > 修改前必须基于最新档案版本生成补丁，并在本地窗口展示修改路径和值，由用户明确允许后才会写入
  >
  > 对集控档案、管理策略、引用关系、保留课表群、时间点和课程数量等内容进行检查；保存失败时会尝试恢复修改前的档案

- **[AI 功能]**: 新增 AI 调用 **ClassIsland 行动** 的能力
  > AI 会先读取当前已注册的行动目录、行动参数结构和应用设置选项，再生成需要执行的行动批次
  >
  > 执行前会在本地列出行动顺序和参数并请求批准；用户拒绝时，批次中的行动均不会运行

- **[AI 功能]**: 新增 **语音输入、连续语音对话和语音唤醒**
  > 支持在 AI 对话中输入语音，或通过唤醒词进入连续语音对话；默认唤醒词为“你好ci”
  >
  > 新增语音对话悬浮窗口、识别状态、语音波形、唤醒/聆听/停止动画和操作审批界面
  >
  > 新增独立 VoskWorker 语音识别进程，支持 Vosk 系列模型与 SenseVoiceSmall ONNX 模型，并提供语音服务及模型的下载、检测和删除功能
  >
  > 语音请求同样可以读取/修改档案或执行行动，但涉及修改和执行时仍需用户批准

- **[行动]**: 新增 **启用语音唤醒 AI** 、 **唤醒语音对话 AI** 、 **显示AI对话框** 行动
  > 可通过自动化启用或关闭语音唤醒、直接启动连续语音对话，或打开 AI 文本对话悬浮窗口
  >
  > 位于 *[ SystemTools 行动 > AI 功能… ]*

- **[触发器]**: 新增 **关键词触发** 触发器
  > 使用 Windows 语音识别持续检测自定义关键词，可设置 0.00–1.00 的识别灵敏度
  >
  > 需要 Windows 中文语音识别支持和可用的麦克风

- **[触发器]**: 新增 **点击主界面时** 触发器
  > 在 ClassIsland 主界面可见行区域上进行左键单击时触发自动化，同时保留原有点击操作
  >
  > 本触发器不提供恢复触发

- **[行动]**: 新增 **行动流执行确认** 行动
  > 自动化执行到该行动时，可选择 **立即执行**、**延迟执行** 或 **停止行动流**
  >
  > 支持自定义确认窗口显示名称，延迟时间可设置为 1–86400 秒
  >
  > 位于 *[ SystemTools 行动 > 高级自动化工具… > 行动流执行确认 ]*

- **[功能]**: 新增可实际使用的 **主界面遮挡文字时自动隐藏** 功能
  > 每两秒检测 ClassIsland 主界面所覆盖区域背后的文字；识别到至少 4 个文字字符时隐藏主界面，否则重新显示
  >
  > 位于 *[ SystemTools 设置 > 更多功能选项… > 主界面遮挡文字时 ]*

- **[功能]**: 新增 **自动清理内存（管理员）** 功能
  > 可在系统物理内存占用达到指定阈值时，清理进程工作集、系统文件缓存、低优先级待机列表和注册表缓存
  >
  > 自动清理阈值可设置为 50%–99%，默认 90%；内存明显回落后才会重新允许下一次自动清理
  >
  > 支持不启用自动清理时手动执行“一键清理”，需要管理员权限和 Windows 8.1 及以上系统
  >
  > 位于 *[ SystemTools 设置 > 更多功能选项… > 自动清理内存（管理员） ]*

- **[行动]**: 新增 **自动切换 ClassIsland 主题** 、 **遮挡文字时隐藏主界面** 、 **自动播放** 行动
  > 可通过自动化分别开启或关闭自动主题切换、遮挡文字时隐藏主界面，以及 U 盘插入后自动打开功能
  >
  > 位于 *[ SystemTools 行动 > 更多功能选项… ]*

- **[悬浮窗]**: 新增 **多配置方案**
  > 每套方案独立保存悬浮窗按钮布局、按钮规则和按钮行规则，可新建、切换和删除配置方案
  >
  > 升级后会把旧版悬浮窗方向、按钮顺序和按钮行布局迁移到默认方案
  >
  > 悬浮窗外观、位置、层级、显示状态和整窗规则仍为全局设置，不随配置方案切换

- **[悬浮窗]**: 新增按钮池、按钮/按钮行显隐和分级规则控制
  > 可把未加入布局的按钮从按钮池添加到指定按钮行，并通过拖放在行内或跨行移动
  >
  > 可分别设置整个悬浮窗、单个按钮行和单个按钮是否显示，以及是否在指定规则满足时自动隐藏

- **[悬浮窗]**: 新增 **液态玻璃外观** 和 **自适应背景主题**
  > 可在经典与液态玻璃外观之间切换，并调整玻璃模糊、折射、背景刷新频率和按钮弹性
  >
  > 主题选项在跟随 ClassIsland、明亮、黑暗之外新增“自适应背景”
  >
  > 新增“一直显示拖动把手”选项

- **[行动]**: 新增 **切换悬浮窗层级** 、 **切换悬浮窗配置方案** 、 **切换悬浮窗主题** 行动
  > 可在置顶/置底之间切换、循环或指定配置方案、循环或指定悬浮窗主题
  >
  > 三个行动均支持恢复执行前状态
  >
  > 位于 *[ SystemTools 行动 > 悬浮窗设置… ]*

- **[验证器]**: 新增 **Windows Hello 验证器**
  > 使用 Windows 安全界面验证身份，并提供配置检测和打开 Windows Hello 系统设置的入口
  >
  > Windows Hello 人脸模板由 Windows 管理，SystemTools 不读取或保存其人脸数据
  >
  > 位于 *[ 应用设置 > 集控选项 > 密码保护限制 > 认证方式 ]*

- **[主题]**: 新增 **Card-type Component** 主题
  > 提供更高的主界面组件布局，并声明 20px 的主界面垂直安全区域

- **[设置页面]**: 新增隐藏的 **插件调试** 页面
  > 可细调 AI 对话液态玻璃的折射、模糊、色彩、渐进模糊、自适应亮度、高光、内外阴影和审批按钮效果
  >
  > 提供语音唤醒 AI 的调试入口；连续点击关于页插件卡片 5 次可进入该页面

- **[通知]**: 新增 **SystemTools 通知提供器** 和 **AI 回复通知** 渠道
  > AI 对话可选择将回复内容发送到 ClassIsland 通知
  >
  > 为模拟键盘/鼠标、键入内容、窗口操作、显示设置、计时关机、锁屏、桌面个性化、设备控制、屏幕截图、系统音量、悬浮窗、临时课表和打开 ClassIsland 页面等多项行动增加“执行时发出提醒”选项

- **[外观]**: 新增关于页顶部标题图片和主题 Banner 缓存
  > 关于页新增 Hoshimi Miyabi 标题图片；缓存不存在时会在后台下载，下载失败时继续使用插件内置图片
  >
  > Card-type Component 主题预览图会保存到 ClassIsland 缓存目录

### 🐛 Bug 修复：

- **[悬浮窗]**: 修正没有任何可用悬浮窗按钮时，**显示悬浮窗** 行动仍可把悬浮窗状态设置为显示的问题
- **[开关自动化]**: 修正未启用“恢复原始状态”时仍进入恢复处理流程的问题
- **[摄像头]**: 修正多个功能同时占用同一摄像头时缺少占用保护，以及停止采集时可能重复释放或遗留帧资源的问题
- **[人脸识别]**: 修正人脸模型初始化、特征提取和资源释放可能并发执行的问题，并补充摄像头启动失败后的恢复与重试处理
- **[系统音量]**: 补充系统音频设备枚举器类型和实例为空时的错误处理，避免以无效对象继续执行

### ◀️ 调整/优化：

- **[插件]**: 版本由 **2.5.1.0** 升级为 **3.0.0.0（Hoshimi Miyabi）**，清单描述增加规则集与 AI 功能
- **[运行环境]**: ClassIsland PluginSDK 由 **2.0.0.1** 升级为 **2.1.1.0**，并适配新的 ClassIsland、Avalonia 与 FluentAvalonia 接口
- **[功能]**: 重做原有 **自动匹配主界面背景色到 ClassIsland 主题** 功能，并更名为 **自动切换 ClassIsland 主题**
  > 旧版按屏幕上方或下方区域取样；新版直接捕获 ClassIsland 主界面实际覆盖区域，并按该区域平均亮度切换明亮/黑暗主题
  >
  > 位于 *[ SystemTools 设置 > 更多功能选项… > 自动切换 ClassIsland 主题 ]*

- **[悬浮窗]**: 重做悬浮窗配置存储和编辑逻辑
  > 保留旧版已有的缩放、图标大小、文字大小、透明度、阴影、明暗主题、置顶/置底和多行布局能力
  >
  > 将按钮布局与按钮/行规则保存到独立配置方案文件，并清理已不存在的按钮 ID

- **[人脸识别]**: 重做 **人脸识别验证器** 界面和运行流程
  > 新增摄像头连接状态、初始化/录入/验证状态、错误信息、自动连续验证和重新启动摄像头入口
  >
  > 验证模式下检测到匹配人脸后自动放行，不再依赖手动反复扫描

- **[摄像头]**: 重构摄像头采集服务的启动、停止、帧复制、异常处理和资源释放流程，并为摄像头索引增加进程内占用保护
- **[行动]**: **沉浸式时钟** 改为直接使用系统默认浏览器打开，不再在打开后模拟 F11 按键
- **[行动]**: 将 **开关自动化** 与 **触发指定触发器** 移入新增的 **高级自动化工具…** 行动组
- **[行动]**: 重新排列 SystemTools 行动组顺序为：**模拟操作、显示设置、电源选项、文件操作、系统个性化、实用工具、悬浮窗设置、媒体工具、更多功能选项、高级自动化工具、AI 功能、其他工具、ClassIsland**
- **[设置页面]**: 主设置新增 AI 服务、Windows Hello、VoskWorker 和语音模型管理；更多功能选项按 ClassIsland 外观、性能和其他工具重新分组
- **[关于页面]**: 新增 Hoshimi Miyabi 版本名称和顶部标题图片
