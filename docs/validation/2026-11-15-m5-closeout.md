## 目前无法代替用户或其他平台完成的部分

1. 新包在 Windows 上的实体摄像头/麦克风回归、Windows Hello 本人成功/取消，以及 Linux 的真实 V4L2/PulseAudio、X11 桌面媒体/歌词、espeak 链路，需要对应系统和设备。本台 Mac 和远程无设备 CI 不能提供这些证据。历史 Windows 设备结果仍保留，但不冒充新包重新实测。
2. 本机使用内置摄像头和麦克风，无法模拟物理拔出。需可拆卸的外接设备验证断开/重连。60 秒真实运行也不等于数小时稳定性、外放回声或中文识别质量已验证。
3. 实际外部 AI 服务需要用户提供端点、模型及运行时凭据；本轮没有读取其他应用的密钥或发送实际商业服务请求。已有本地 HTTP/审批夹具和打断检查不代表外部服务质量。
4. 正式 Developer ID 签名、公证和升级授权稳定性属于 M7。本机没有可用代码签名身份，不能自行完成；当前助手保持开发签名。
