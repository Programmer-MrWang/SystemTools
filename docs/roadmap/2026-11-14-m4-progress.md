# M4 逐批开发、自审与回退记录

日期：2026-11-14，Asia/Shanghai。主分支 codex/cross-platform。

执行顺序：M4.0 → M4.1a 音量 → M4.1b 空闲 → M4.2a 截图 → M4.2b 设备 → M4.3a 热键/输入 → M4.3b 窗口/浮窗 → M4.4 壁纸 → M4.5 集成。每批编译和相关检查后自审，再中文约定式提交及通过本机代理推送。

## M4.0 原生接入约定

新增窄能力接口与原生服务容器；后续非 Windows 后端在共享业务初始化之外提供原生服务。Windows 的 IPlatformPlugin 路径保持原样。能力 Probe 只读，不请求 TCC；原生错误按缺设备、缺依赖、权限不足和不支持分别反馈。服务实例由入口生命周期统一释放，重复 Dispose 无操作，一项失败继续释放其他资源。

| 功能 | Mac 后端 | Linux 后端 | 线程/释放 | 运行验收边界 |
| --- | --- | --- | --- | --- |
| 音量 | Core Audio C API | PulseAudio 协议的 pactl | 后台调用；每次重取设备 | Mac 读回；Linux 待 x64 实机 |
| 空闲 | Quartz | XScreenSaver | 后台采样；触发器取消轮询 | 锁屏/唤醒独立记录 |
| 截图 | ScreenCaptureKit | X11 图像 | 异步采集；取消不提交文件 | 需要录屏权限、真实桌面 |
| 设备 | IOKit、卷就绪 | udev/sysfs、UDisks | 可取消监测；按物理设备去重 | USB 实物插拔独立记录 |
| 热键/输入 | Carbon、Quartz | XGrabKey、XTest | 注册句柄/按下键必须释放 | TCC 需用户实际授予 |
| 窗口 | Accessibility/AppKit | EWMH | 明确窗口身份、Mac 主线程 | 不把普通层级称置底 |
| 壁纸 | NSWorkspace | 桌面环境适配 | Mac 主线程；检查读回 | 不支持的布局明确失败 |

本机不具备 Windows/Linux 桌面，编译与托管测试不等于目标 OS 实测。没有执行的权限、设备及发行场景保留待验收。初始 M4.0 不新增菜单入口。

自审：核对没有修改稳定功能 ID、Windows 初始化、配置模型或旧密文；服务容器区分实例去重与重复关闭。后续按批追加实际结果与问题。

## M4.1a 系统音量

Core Audio 读取默认输出设备，检测可写主音量属性，设置后读回；固定音量设备明确不可用。Linux pactl JSON 解析默认 sink，向明确设备 ID 设置并读回，不借用播放器音量。中立入口先注册 SharedHost 再注入原生服务，Windows 初始化不改。沿用 SetVolume ID、旧设置及通知。

检查：Mac/中立入口构建 0 警告 0 错误；11 项测试含非法参数、Mac 实际读写和恢复原音量通过。Linux 后端在 Mac 编译，尚无 Linux 音频实测。自审：修正遗漏的执行通知，确认取消在写入前检查、设备按明确 ID 操作，未新增音量恢复语义或改 Windows 行为。日志 artifacts/m4/volume.log。

## M4.1b 空闲监测

Mac 使用 Quartz 的共享会话空闲时长，Linux 使用 XScreenSaver/Xss；共享状态机沿用一分钟最小阈值、只触发一次和重新活动后恢复。轮询串行执行，UnLoaded 与插件停止均取消，单次失败保留状态、不伪造活动事件、日志不按秒重复。

检查：中立入口与两后端编译 0 警告 0 错误，阈值、防重入、恢复及真实 Quartz 读取通过。自审补上入口停止令牌，避免宿主停止而未卸载触发器时遗留轮询。第一次并行 MSBuild 子节点异常退出，读诊断目录无文件；串行构建成功，保留实际日志。锁屏/睡眠和 Linux X11 真机仍需对应环境验收。
