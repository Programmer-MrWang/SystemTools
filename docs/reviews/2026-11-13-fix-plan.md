# 跨平台插件修复计划

范围：处理 2026-11-13 源码审查问题，覆盖 Windows/Linux/macOS，不涉及 Android。

用户决策：移除不再维护的外部网页行动及相关界面、注册和文档；保留 Windows 普通退出无条件执行 shutdown /a 的现有行为。

按以下顺序实施，每批独立审查、验证并以中文约定式提交：

1. [已完成] 目录操作：恢复根目录和路径重叠校验，处理链接环，避免失败前破坏已有数据；添加回归验证。
2. [已完成] 宿主集成：隔离菜单根名称，删除用户指定移除的外部网页功能，校正文档。
3. [已完成] 关机状态：统一普通/高级计划的创建、替换、取消和到期状态，使界面与实际计划同步。
4. [已完成] 平台命令：异步执行并允许授权等待，区分超时失败与已发起，支持中断。
5. [已完成] 行动恢复：按目标和行动项保存恢复状态，处理同组多项行动；工作流引用改用稳定 GUID 并兼容旧配置。
6. [已完成] 音频与 macOS：等待音频接入中断令牌；按宿主能力降级不支持的窗口层级。
7. [已完成] 收尾：修复 SDK 版本格式、补齐关于页资源，重新编译并核对全部问题；更新完成记录。

验证原则：使用真实源码的针对性回归检查和插件编译；不运行真实关机、重启、睡眠、锁屏。Windows/Linux 实际桌面行为如无法验证会明确记录。构建时关闭 CreateCipx，保护已有包和调试配置。用户原有未提交改动单独保留，不混入修复提交。

完成记录：48 项核心回归检查及 6 项宿主契约检查通过；Release 构建通过；原有调试配置及包文件已做字节对照。每批检查和具体平台限制见审查修复结果。
