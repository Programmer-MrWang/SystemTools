## 已实现

1. 行动流确认；共享行动信号与主界面点击；中文路径音频、等待/后台和取消；可退出的全屏黑屏窗口。
2. Mac/Linux 逻辑快捷键、Unicode 键入和坐标鼠标序列；目标变化停止、取消释放；受控精确进程名退出。
3. 插件计时关机/高级倒计时/延长/取消及电源/会话行动；宿主停止取消未派发计划，按行动项归属回退，不误取消后来的计划。自动检查从未执行真实关机、重启、睡眠或锁屏。
4. Mac 通过自有助手白名单请求 System Events；Linux logind/systemctl/X11 及实际 GNOME schema 外观。系统主题条件恢复不覆盖用户后续改变；Windows 专属和无可靠接口的能力明确保留边界。
5. Mac Keychain、Linux Secret Service，配置只保存随机引用，显式保存/移除和原会话路径并存。保存冲突恢复内存并清理新项目；旧平台密文不自动覆盖；Linux 命令不在参数传密钥、服务失败不降级明文。
6. 修复 Mac TIS 键盘布局必须主线程查询、宿主 JSON 行动工厂的直接泛型设置契约、跨临时行动实例的状态恢复，以及材质实时诊断/轮询释放。

## 失败、纠正与未完成项

输入夹具被系统无参数重开时崩溃，已修复安全参数回落及应用包启动，原报告保留为调试证据。标准编辑菜单缺失造成的撤销测试失败、背景夹具未覆盖正确 Space 造成的 OCR 空结果，也已定位并修正，后续对应路径通过；包含早期失败的整个会话报告仍为 false，没有抹去失败计数。

本机最小化在 AppKit 自身、系统按钮和 AX 三条路径均未确认成功，仍明确失败反馈。外屏/USB 用户确认暂时没有；旧 macOS、多屏/Spaces/背光/DDC、数小时使用和非本机桌面不填成功。

2026-11-16 本机进入锁屏后，界面工具无法获取窗口，系统会话明确 ScreenIsLocked=Yes。已通知用户并请求解锁；没有绕过认证或修改锁屏策略。最终包 JSON 行动路径、材质减少透明度/增强对比度切换、最终桌面新装/升级/回退/卸载及历史合成凭据清理仍待解锁。

7 项历史合成 Keychain 引用来自本轮独立 sandbox 的配置/备份，锁屏时非交互清理 0/7，需原宿主解锁后清理。它们不是用户真实 API 密钥，不搜索全局钥匙串。清理清单在 artifacts/m8/synthetic-keychain-cleanup.json。
