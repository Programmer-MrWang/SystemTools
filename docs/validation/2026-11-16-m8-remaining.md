# M8 剩余验证

本轮目标是补齐可迁移功能、这台 Mac 能完成的交互，以及 Mac/Linux 系统凭据存储。对应源码已实现并按批次自审、中文提交/代理推送；以同目录结果报告确认最终包与检查结果，不从开发预览推断最终候选包已完成全量桌面验收。

## 需要解锁后继续

- 最终候选包在原版宿主中，使用真实 JSON 行动工厂复核保存/重载、系统凭据读写与启停清理。
- 通过系统设置切换减少透明度/增强对比度，观察自有玻璃测试窗口实时回退与恢复，随后恢复原设置。
- 清理本轮历史测试 sandbox 引用的 7 项合成 Keychain 项目。锁屏非交互删除被系统拒绝；只使用 artifacts/m8/synthetic-keychain-cleanup.json 中的本轮引用，通过原宿主测试面板清理，不检索或删除用户真实凭据。
- 实际空闲触发器的阈值及恢复/去重最终包复核。先前真实一分钟只读采样已通过，不能等同于所有锁屏/睡眠/唤醒场景。
- 正常、异平台损坏、本机后端缺失、升级/回退/卸载的最终包桌面复验。M7 的旧包验收不替代 M8。
- AltTab/关闭窗口的实际目标行为、背景音频取消/宿主退出、原生材质及隐藏恢复的最终包交互复验。此前开发预览通过项单独保存。

## 需要对应设备或系统

- 当前 AppKit 自身 miniaturize、系统按钮及 AX 请求均未确认最小化状态；保留失败反馈，需在正常 Dock/窗口会话或另一环境对照，不能写成成功。
- 外接屏、USB 物理插拔、多屏/Spaces/不同 DPI、硬件亮度/DDC，用户已确认暂时没有所需设备。
- 较旧 macOS 原生磨砂外观，以及数小时运行、全部课表布局、睡眠/唤醒和权限撤销的覆盖。
- Windows/Linux 真实桌面与实体设备。Linux CI 已实际使用隔离 D-Bus 和 GNOME Keyring 验证 Secret Service；这不等于 GNOME/KDE 桌面全部通过。
- 正式签名、公证和发行属于前轮已冻结的独立门禁，本轮没有 Developer ID 条件，不发布。

## 明确平台边界

六项 Windows 专属入口保持专属；Mac 通用显示桌面、任意系统强调色及关闭单屏不冒充可靠公共支持。Linux 背景/OCR、系统认证、Wayland/XWayland 仍按原边界；Linux 系统外观仅在实际 GNOME schema 可用时开放。Mac 通用媒体规则/歌词不作为已支持能力。
