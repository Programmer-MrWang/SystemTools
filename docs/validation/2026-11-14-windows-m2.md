## 本地复验

在 SystemTools 执行：

~~~powershell
python -X utf8 eng/m1.py build --clean
dotnet build VoskWorker/SystemTools.VoskWorker.csproj -c Release
python -X utf8 eng/test_m1_packaging.py
python -X utf8 eng/test_m2_packaging.py
python -X utf8 eng/check_reproducible.py
python -X utf8 eng/m2.py stage --host-bin <真实桌面宿主路径>
python -X utf8 eng/m2.py package
python -X utf8 eng/m1.py test --stage artifacts/m2/stage
python -X utf8 eng/m2.py smoke --host-bin <真实桌面宿主路径> --package artifacts/m2/SystemTools.M2.cipx --case normal --missing-dependencies --experimental
~~~

stage 不传 host-bin 时使用 SDK 依赖闭包，明确标记 build-only，供 CI 打包使用；不把 SDK 契约当作宿主运行通过。旧 m1.py package/prototype 不适用于 M2 私有依赖格式，工具会拒绝，避免漏包。
