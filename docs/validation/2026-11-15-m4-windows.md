## 本轮修复与复验入口

旧 Windows smoke 在缺本机后端时读到加载错误便直接终止宿主，最初运行 `20261115-164456-missing-backend` 的退出码为 1；该记录保留，不能记正常退出。本轮新增 `SystemTools.M4.WindowsProbe`，仅在显式隔离目录加载，读取真实宿主错误状态并请求正常停止；脚本记录超时/强制停止，且异常停止不会冒充通过。

```powershell
$env:DOTNET_ROOT = 'C:\STWork-Windows\.dotnet'
$env:PATH = $env:DOTNET_ROOT + ';' + $env:PATH
Set-Location C:\STWork-Windows\SystemTools
py -3 eng/m4.py smoke-windows --host-bin <真实宿主exe> --package <最终M4.cipx>
```

工具改动后实际重新运行三场景，全部正常退出；相关 M2 打包边界 11 项亦通过。最终证据在 `artifacts/m4/windows/desktop.json` 和上述 `runs` 目录；可提交的结构化摘要与证据哈希见同名 JSON。

工具提交 `656104b` 推送后，CI `43696195206` 的 Windows x64、Linux x64、Mac ARM64 三个原生任务及严格 aggregate 四项全部成功。此轮 CI 是工具改动后的构建回归证据；本轮桌面结论仍绑定上文原最终包哈希，未将新 CI 产物替换为已验收包，也未发布。
