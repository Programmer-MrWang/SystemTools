# M8：补齐可迁移功能、Mac 交互与系统凭据

范围来自用户对上轮清单 #1、#3、#4 系统凭据存储的明确要求。保持 ClassIsland 源码与已安装应用不变，精确 SDK 10.0.403；沿用自审、中文约定式提交和代理推送。原有 IDE/PROJECT_STATE 迁移纠正和 docs/reports 不夹入提交。

| 顺序 | 工作 | 验证 |
| --- | --- | --- |
| 1 | 共享行动确认、行动/主界面触发器、背景音频及黑屏 | 公共契约与实际宿主/UI 操作、停止释放 |
| 2 | 输入快捷键、键入内容、鼠标、进程与电源行动 | 目标捕获、取消释放、受控夹具；实际关机/重启不自动执行 |
| 3 | 系统外观的真实可用接口和能力边界 | 不用私有偏好写入冒充系统 API；明确平台可用性 |
| 4 | Mac Keychain、Linux Secret Service 与凭据设置 | 合成密钥真实增读删/重启；拒绝时保留旧密文、不落明文 |
| 5 | Mac 热键/组合键/空闲/窗口/课表与长期运行交互 | 尽量 computer use，实体设备和本人认证缺口独立记录 |
| 6 | 三端 CI、同源候选包、回归与文档收尾 | 基于实际产物验证，不以 Mac 交叉编译冒充 Linux 实测 |

Mac/Linux 完全同名功能不等于所有平台系统接口相同。无公开可靠接口、Windows 专属、Wayland/Intel Mac 的既有边界保持，并逐项解释。Linux 真实 Secret Service/桌面、多屏/USB 物理操作若环境不具备，向用户列明，不填成功。
