# 系统凭据存储

Mac 使用当前用户 Keychain 的 Generic Password 项目；Linux 使用当前登录会话 Secret Service（libsecret 的 secret-tool），需要可用、已解锁的密钥环及 D-Bus 会话。配置文件只保存随机引用。Linux 的密钥内容经标准输入传入，不进入命令参数；服务失败不回退明文。Windows 保持原 DPAPI。

在“相机、语音与媒体”中，输入框默认是本次会话密钥；只有按“将输入的密钥保存到系统凭据”才持久保存。普通保存时留空不覆盖现有系统密钥。保存失败保留原配置；配置并发写入失败时恢复内存并清理本次新项目。

旧 DPAPI/其他平台引用无法读取时保持原字节，不自动清空或改成空密钥。保存新密钥不会删除旧系统项目，避免破坏旧配置备份和版本回退；需要删除时使用显式移除。移除当前系统项目会让仍引用它的历史备份不可读取；配置/备份不是跨机器密钥导出文件。配置清除成功而系统删除失败会明确报告部分完成。

Mac 的访问权限由真正运行插件的宿主应用身份控制；本机 dotnet 合成凭据已完成写入、读取、跨进程重开和删除。最终宿主和升级后的身份仍独立验证，不更改 ClassIsland 签名或放宽系统 ACL。Linux 代码和公共契约不等于真实桌面密钥环已验收。
