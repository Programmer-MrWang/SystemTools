# M4 逐批开发、自审与回退记录

日期：2026-11-14，Asia/Shanghai。主分支 codex/cross-platform。

执行顺序：M4.0 → M4.1a 音量 → M4.1b 空闲 → M4.2a 截图 → M4.2b 设备 → M4.3a 热键/输入 → M4.3b 窗口/浮窗 → M4.4 壁纸 → M4.5 集成。每批编译和相关检查后自审，再中文约定式提交及通过本机代理推送。

## M4.0 原生接入约定

新增窄能力接口与原生服务容器；后续非 Windows 后端在共享业务初始化之外提供原生服务。Windows 的 IPlatformPlugin 路径保持原样。能力 Probe 只读，不请求 TCC；原生错误按缺设备、缺依赖、权限不足和不支持分别反馈。服务实例由入口生命周期统一释放，重复 Dispose 无操作，一项失败继续释放其他资源。

| 功能 | Mac 后端 | Linux 后端 | 线程/释放 | 运行验收边界 |
| --- | --- | --- | --- | --- |
| 音量 | Core Audio C API | PulseAudio 协议的 pactl | 后台调用；每次重取设备 | Mac 读回；Linux 待 x64 实机 |
| 空闲 | Quartz | XScreenSaver | 后台采样；触发器取消轮询 | 锁屏/唤醒独立记录 |
| 截图 | ScreenCaptureKit | X11 图像 | 异步采集；取消不提交文件 | 需要录屏权限、真实桌面 |
| 设备 | IOKit、卷就绪 | udev/sysfs、UDisks | 可取消监测；按物理设备去重 | USB 实物插拔独立记录 |
| 热键/输入 | Carbon、Quartz | XGrabKey、XTest | 注册句柄/按下键必须释放 | TCC 需用户实际授予 |
| 窗口 | Accessibility/AppKit | EWMH | 明确窗口身份、Mac 主线程 | 不把普通层级称置底 |
| 壁纸 | NSWorkspace | 桌面环境适配 | Mac 主线程；检查读回 | 不支持的布局明确失败 |

本机不具备 Windows/Linux 桌面，编译与托管测试不等于目标 OS 实测。没有执行的权限、设备及发行场景保留待验收。初始 M4.0 不新增菜单入口。

自审：核对没有修改稳定功能 ID、Windows 初始化、配置模型或旧密文；服务容器区分实例去重与重复关闭。后续按批追加实际结果与问题。

## M4.1a 系统音量

Core Audio 读取默认输出设备，检测可写主音量属性，设置后读回；固定音量设备明确不可用。Linux pactl JSON 解析默认 sink，向明确设备 ID 设置并读回，不借用播放器音量。中立入口先注册 SharedHost 再注入原生服务，Windows 初始化不改。沿用 SetVolume ID、旧设置及通知。

检查：Mac/中立入口构建 0 警告 0 错误；11 项测试含非法参数、Mac 实际读写和恢复原音量通过。Linux 后端在 Mac 编译，尚无 Linux 音频实测。自审：修正遗漏的执行通知，确认取消在写入前检查、设备按明确 ID 操作，未新增音量恢复语义或改 Windows 行为。日志 artifacts/m4/volume.log。

## M4.1b 空闲监测

Mac 使用 Quartz 的共享会话空闲时长，Linux 使用 XScreenSaver/Xss；共享状态机沿用一分钟最小阈值、只触发一次和重新活动后恢复。轮询串行执行，UnLoaded 与插件停止均取消，单次失败保留状态、不伪造活动事件、日志不按秒重复。

检查：中立入口与两后端编译 0 警告 0 错误，阈值、防重入、恢复及真实 Quartz 读取通过。自审补上入口停止令牌，避免宿主停止而未卸载触发器时遗留轮询。第一次并行 MSBuild 子节点异常退出，读诊断目录无文件；串行构建成功，保留实际日志。锁屏/睡眠和 Linux X11 真机仍需对应环境验收。

## M4.2a 主屏截图

Mac 在宿主内使用 ScreenCaptureKit，权限发现只读；独立“系统功能与权限”页提供明确请求按钮。Linux XRandR 选择主显示器，XGetImage 与像素掩码转换成 PNG。共享行动生成唯一文件名、先写临时文件、验证 PNG 后提交；取消与失败删除临时文件。

自审：修复 Swift 异步锁警告及采集超时后继续写文件的竞态；修复原生库去掉 LC_UUID 后被当前 dyld 拒绝加载，改为固定 install_name 与可复现链接；Linux 从全根窗口改为主监视器。构建零警告零错误；Mac 原生桥接成功加载，权限只读检查及预取消测试通过。本机未自动授予录屏权限，实际授权截图与多屏像素结果保留对应实测项。

## M4.2b USB 与挂载

Mac 用 IOKit 物理 USB 身份和 DiskArbitration 卷到设备关联，Linux 用 sysfs 物理路径与 lsblk 挂载快照。每秒串行采样而非伪造系统通知；启动已有设备不触发，存储卷就绪才触发，多分区按物理设备去重，拔出后重新插入可再次触发。自动播放沿用旧配置开关，使用宿主 LaunchPath，不拼 shell。

自审：补上 Linux lsblk 依赖探测，避免能力显示可用后才发现工具缺失；处理监测先结束后 UnLoaded 再取消的已释放令牌；后台服务停止等待采样退出。Mac 只读 IOKit/卷查询与状态机的启动、就绪、多分区、拔插检查通过；无真实 USB 插拔证据，Linux 实机及设备竞争场景明确待验收。构建零警告零错误。

## M4.3a 热键与输入

Mac Carbon 注册热键并报告冲突，Quartz 发送按键与 Unicode；字符键按当前键盘布局查询，不按 Windows VK 直接发送。Linux XGrabKey 处理锁定修饰键与注册冲突，xdotool/XTest 发送输入。共享录制界面保存逻辑键/间隔/文本，保留原 Windows 键字段，未知映射明确失败。输入捕获原目标，后续失焦停止；每个输入服务串行执行，取消/异常逆序释放按键。

自审：补上并发输入互斥、未知操作类型拒绝、Linux 注册错误捕获与释放；Mac 热键轮询失败记录并注销。控制台探测曾因错误等待 AppKit 主线程挂起，已将无副作用能力探测移到主线程分派之外并重跑。29 项公共/本机只读检查通过，构建零警告零错误。没有向日常应用发送模拟输入；真实权限、测试窗口 Unicode、热键冲突/撤销与 Linux X11 回调仍需独立桌面验收。

## M4.3b 窗口与浮窗

Mac 使用 Accessibility 操作明确活动窗口，最大化保存位置/尺寸，恢复按原窗口身份还原；Linux 使用 EWMH 工具并对最小化/最大化/还原与置底读取状态确认，关闭只请求关闭不终止进程。共享浮窗使用原按钮身份、方案、行/按钮规则与主题开关，点击支持触发与恢复，四类行动使用持有者快照。Mac 置底明确失败，旧配置保留并在普通层级回退时给出状态，不冒充置底。

自审：将 Mac 的 zoom 切换改为明确最大化几何及原位置恢复；补上浮窗随入口停止同步关闭、事件退订与原生窗口记录释放；保留全窗规则语义和通知。34 项检查含窗口能力、置底拒绝、同组恢复通过，两后端及入口零警告零错误。真实外部窗口行为和浮窗显示将在隔离宿主中继续验收，Linux 桌面结果未声明通过。

## M4.4 壁纸与联动

Mac NSWorkspace 按显示器读写壁纸及布局，GNOME 使用 gsettings、KDE 使用 Plasma D-Bus；其他桌面环境与无法准确映射的布局明确不可用。纯色生成持久 PNG，图片先校验再更改桌面；共享取色用于主题色与浮窗自适应深浅。恢复比较当前壁纸和行动写入结果，用户随后修改时拒绝覆盖。

自审：补上取消发生在系统写入之后时恢复原壁纸、部分平台写入失败回退；将壁纸更改成功与后续取色失败分开反馈；主题色跟随尊重宿主手动修改并退订/恢复。37 项公共与本机只读检查通过，两后端和 Swift 桥接零警告零错误。实际桌面更换/恢复与多屏行为进入隔离宿主验收；Linux GNOME/KDE 实机仍待验证。


## M4.4 补充：宿主验收发现的原生崩溃

20:22 的隔离宿主运行在读取壁纸快照时 SIGABRT，未记为通过。用户提供的崩溃报告明确指向 wallpaperRows → NSColor.redComponent。缺省填充色回退为灰阶 NSColor.black 后直接读取 RGB 分量，会抛出无法由 Swift/C# 普通 catch 捕获的 Objective-C 异常。

修复：仅对已转换到 sRGB 的颜色读取分量；缺省及不可转换的颜色直接返回数值黑色。原生回归直接链接生产 Swift 源码，覆盖缺省、黑白灰阶、RGB、图案色与真实桌面只读快照，7 项通过。自审确认读路径没有写入壁纸、请求权限或更改日常配置。保留 artifacts/m4/desktop-initial.json 的失败证据，完整宿主复验继续在 M4.5 进行。

复验命令：`xcrun swiftc -swift-version 5 -O native/macos/SystemToolsNative.swift tests/SystemTools.M4.NativeTests/main.swift -o /tmp/systemtools-m4-native-tests && /tmp/systemtools-m4-native-tests`。


## M4.4 补充：壁纸异步生效确认

崩溃修复后的宿主正常退出，但第一次壁纸写入后立即读回仍为旧值，保留为失败。独立原生探测确认约 200ms 后读回新壁纸，恢复也存在同样的异步边界。新增后台有界确认（单调时钟，最多 3 秒），同时比较图片、显示器及布局；写入和恢复均等到真实读回后返回。AppKit 主线程拒绝等待；异常回退仅覆盖仍匹配本次写入的显示器，保留随后由用户修改的状态。读取路径与快照由同一批数据产生。

自审及验收：原生回归增至 8 项；真实 ARM64 宿主正常运行 131 项业务检查、3 项停止检查均通过，壁纸更换/取色/完整快照恢复和实际 ScreenCaptureKit PNG 解码通过。机器级配置哈希不变，退出码 0。证据：artifacts/m3/mac/runs/20261114-204228-native-normal。后续 M4.5 使用最终聚合包再次跑隔离场景。


## M4.5a 窗口状态确认与停止容错

自审修复：窗口几何先移动再调整尺寸，避免在屏幕边缘被系统裁剪；主线程只发起 AX 操作，后台有界读回状态，不阻塞自身 AppKit 布局。窗口失去 focused 属性时只回退到系统明确标识的 main window，不枚举猜测目标。恢复成功后才移除原位置记录。关闭按钮验证 AX 类型，保持请求关闭、不终止目标应用。

停止回调异常不再中断原生资源释放；同一服务实例只释放一次，错误汇总后上报，重复 Dispose 幂等。新增合成资源回归，确认回调失败仍释放资源。

真实宿主及独立 AppKit 合成目标：最大化、原位置尺寸恢复、关闭后正常退出通过；本机会话直接 miniaturize/performMiniaturize 也未改变状态，最小化实际成功不计通过，仅确认插件明确失败，保留待实机复验。20261114-224031-native-normal 完成 143 项业务与 6 项停止检查，退出码 0、Global.json 哈希不变。所有失败日志均保留。原生回归新增主线程窗口等待拒绝检查。
