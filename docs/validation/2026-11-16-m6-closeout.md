## 交付行为与限制

Mac 使用系统原生玻璃/磨砂，并尊重减少透明度与增强对比度；Linux 缺少可靠捕获/合成器后端时禁用背景明暗/OCR，玻璃使用明确实色退路。显示布局有读回、15 秒确认和条件回滚；Mac 仅提供可靠公共 API 支持的镜像/扩展。亮度区分 IOKit/sysfs 内置背光与可选 m1ddc/ddcutil 外屏 DDC，软件变暗不作为硬件背光。

当前 Mac 没有第二屏，也没有可用公共 IOKit 背光接口或 m1ddc。双屏真实切换/热插拔、外屏 DDC、Windows/Linux 本轮实体设备、旧版 macOS 视觉和所有课表布局长期表现不能在本台替代验收，具体见 2026-11-16-m6-platform-checklist.md。签名、公证、升级/回退/卸载和发行属于 M7，本轮未发布。
