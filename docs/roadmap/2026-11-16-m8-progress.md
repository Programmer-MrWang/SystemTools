# M8 逐批自审记录

## 1：共享交互与媒体行动

复用原行动流确认与设置，接入两项触发器；背景音频支持中文路径、等待或后台、取消和宿主停止；黑屏使用自有可退出全屏窗口，不通过浏览器抢发 F11。主界面触发器使用 Avalonia 输入事件，在穿透模式下明确不触发，未冒充 Windows 全局鼠标钩子。

Release 编译与 121 项共享回归通过。自审修正新行动菜单重复和后台播放取消/释放竞争；新增窗口由宿主停止生命周期统一关闭。实际 UI/音频及取消行为会在最终 Mac 探针中验证，当前编译不作人工交互证据。

## 2：Mac Keychain 与 Linux Secret Service

接入独立凭据后端和明确的保存/移除按钮。Mac 使用系统 Generic Password；Linux 经 secret-tool 标准输入保存、随机属性定位，要求当前用户 D-Bus/密钥环。配置仅保存引用，错误拒绝时保留原密文与会话路径。

本机 12 项原生凭据检查通过，用户本人允许系统钥匙串弹窗；包括跨进程重新读取、合成项目删除及删除后拒绝。后续新增 2 项配置写入冲突保护，总计 7 项凭据契约与 121 项共享回归通过。自审修正“配置保存失败但先删除旧密钥”的风险，失败恢复内存并清理本次新项目；历史系统项目保留供旧配置回退。正式宿主与 Linux 实际服务仍须单独验收，未把 dotnet 授权冒充宿主证据。

## 3：平台输入、电源与系统外观

新增 Mac Quartz/Linux XTest 鼠标、逻辑快捷键及 Unicode 键入、精确进程名退出；计时关机共享取消状态机、自有高级倒计时窗口，宿主停止取消待执行计划。Mac 系统请求经自有助手白名单 AppleScript，新增助手自动化用途与 entitlement；Linux 使用 logind/systemctl、X11/EWMH 和实际 GNOME schema。Mac 显示桌面/任意系统强调色、其他 Linux 桌面的系统外观保持明确边界。

Release 构建通过，13 项新增凭据/计划/输入契约和完整既有 M7 回归通过。自审改进取消时鼠标释放、失败反馈、中文路径和设置可编辑性，避免将 JSON 编辑器作为普通鼠标步骤界面。没有自动执行真实电源操作；Mac 实际输入/自动化授权和 Linux 桌面仍需后续探针。平台表同步由同一台账生成。

## 4：Mac 交互工具与三端验证接入

新增独立 AppKit 文本/鼠标夹具与实际宿主操作面板；通过 computer use 已操作行动确认延迟/取消/继续、黑屏 Esc 退出、中文路径真实音频播放和关机计划取消。原版宿主实际写入系统钥匙串引用，系统主题经自有助手切换/读回/恢复成功。

实际组合键发现原键盘布局查询在后台线程触发 TIS 队列断言；已限制到主线程。测试夹具被 LaunchServices 无参数重开时直接索引参数导致崩溃，已改为安全回落到包目录并使用应用启动、清理旧实例。另为文本夹具启用撤销管理，后续真实组合键/鼠标/最小化仍需复验。

M8 CI 接入完整既有回归、13 项新契约及隔离 D-Bus 中的真实 Linux Secret Service 增读删检查。Mac/Linux 当前源码构建通过；本机并行启动桌面时，离线安装测试按设计拒绝操作，待关闭宿主后再完整复验。自审保持失败证据，不将失败夹具计入通过项；外屏/USB 用户确认暂时没有，继续明确 pending。

### 原生服务与夹具自审纠正

首轮 M8 CI 的 Windows/Mac 构建与回归通过，Linux 独立总线的密钥环初始化遇到交互创建提示。改用明确隔离 XDG 目录和非空的公开合成口令初始化一次性 keyring，避免读取 runner 既有密钥环；凭据测试仍实际调用 Secret Service，不改成模拟成功。

Mac 实际热键由用户按键触发成功；原版宿主保存/重启读取系统凭据、系统主题切换及恢复通过。文本夹具补上标准编辑菜单后，撤销、全选、取消释放和鼠标按钮实际通过。最小化的 AppKit 自身基线仍未改变状态，继续保持具体环境待验，不用 AX 写入成功替代状态读回。

## 5：实机结果扩展与最终验证准备

修正后的 CI 43758152753 三端及严格聚合全部通过，Linux 隔离 XDG/密钥环中的实际 Secret Service 增读删与跨进程重开成功；本机完整 M8 回归 356 项通过。Mac 真实输入、撤销、全选、取消后修饰键释放、鼠标点击已通过；物理热键由用户本人触发成功。宿主保存/重启读取/删除合成钥匙串项目、助手系统主题切换与读回恢复通过。

完善主界面点击/行动信号、受控进程退出和背景隐藏恢复/两分钟测量的验收面板；重复宿主启动通知由一次性守卫隔离。平台表将六项既定 Windows 专属入口明确标记为平台边界。Mac 最小化仍为具体环境 pending，AppKit 自身基线与 AX 都未产生状态变化；旧系统、多屏/USB 和数小时使用没有伪造结果。

## 6：保存重载契约与材质诊断自审

发现宿主行动工厂仅从直接基类读取泛型设置参数；非泛型中间基类导致 JSON 配置重载后设置缺失。将快捷键/会话/显示中间基类改为显式泛型，新增 6 项宿主契约检查，并让实际宿主探针全部从 JSON 行动工厂创建行动。未修改宿主。

原生材质已监听辅助功能设置变化，但共享诊断只报告初始结果。新增租约状态读取与有界轮询，状态变化反馈到共享层，关闭/卸载取消轮询并释放租约。更新随包 README 的持久凭据说明。

全部 362 项本机回归与 Release 构建通过。实际主界面点击、受控进程退出、背景区域隐藏/移除文字后恢复、约 132 秒连续捕获/OCR 和真实空闲采样已有预览证据；首次失败由外部夹具未覆盖宿主所在 Space 引起，采用全空间浮动夹具后通过。最终包仍需复核实际产物与 JSON 行动路径；多屏/USB、旧系统和数小时使用继续独立待验。

## 7：恢复所有权与锁屏边界

锁屏期间完成第二轮生命周期自审：系统外观恢复改用共享事务服务，能跨宿主临时行动实例恢复并保留用户后续手动设置；黑屏窗口按行动项归属释放；计时计划按行动项归属取消，避免旧行动回退取消新计划；普通计时的 ShowPrompt 使用自有倒计时窗口。旧操作的迟到错误不覆盖新计划状态。Linux secret-tool 的 stdin 写入也纳入统一 15 秒超时。

新增原生凭据后，旧验收夹具的非法伪 DPAPI 前缀会触发明文迁移，已改为真实受保护前缀验证跨平台密文保留。只从本轮生成的独立 sandbox 提取 7 项历史合成 Keychain 引用用于清理；锁屏时非交互删除正确拒绝（0/7），需解锁后由原宿主执行，未访问用户真实密钥。

最终本机回归 367 项通过。屏幕锁定已由系统会话状态确认，已向用户请求解锁；未绕过登录或改系统锁屏设置。正式桌面复核和上述历史合成项目清理保持待办，继续并行生成最终三端包。
