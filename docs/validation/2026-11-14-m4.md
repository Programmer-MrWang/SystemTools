# M4 开发与分层验收

记录起于 2026-11-14，更新于 2026-11-15，Asia/Shanghai。M4.0–M4.5 开发、自审及三端原生 CI 汇总完成；最终原生聚合包的 Mac 三场景桌面复验已通过。M4 的开发关闭与完整发行/硬件验收分别记录。

## 实现范围

M4.0 至 M4.4 已按顺序接入音量、空闲、主屏截图、USB 卷就绪及自动播放、全局热键/逻辑键/Unicode 输入、窗口/浮窗、壁纸及取色联动。公共设置、行动生命周期与恢复快照位于 SharedHost；Mac/Linux 原生实现分别位于各后端。Windows 继续保留原实现及依赖，稳定 ID、GUID、资源 URI、旧字段、Windows 密文和未知配置字段兼容。

Mac 仅 ARM64；Linux 仅 x64 原生 X11，拒绝 Wayland/XWayland。Mac 置底、壁纸平铺和跨屏拼接明确不可用；Linux 壁纸仅适配 GNOME/KDE。语音、相机、人脸、跨平台认证和复杂玻璃效果不在 M4 范围。沉浸式时钟继续移除，ClickSimulation 继续不登记。

Mac 本机解决方案与三目标交叉构建为 0 警告、0 错误；远端原生构建保留依赖审计和 Dlib RID 等现有警告，不能将本机零警告推广为所有环境均零警告。此次不迁移 NPOI/Dlib 等既有依赖版本。

## 本轮问题及修复

- 壁纸缺省填充色回退到灰阶 NSColor.black 后读取 RGB 分量，导致 Objective-C 异常和宿主 SIGABRT。改为只读取已转换为 sRGB 的颜色；缺省/无法转换的颜色采用数值回退，原生测试直接链接生产 Swift。
- NSWorkspace 写入/恢复返回后，桌面服务尚未更新。新增后台单调时钟有界确认，比较图片、布局及显示器，失败回退保留用户随后修改的状态。
- AX 窗口尺寸请求在屏幕边缘先缩放会被裁剪。改为先移动再调整尺寸，并在主线程之外等待读回；恢复成功后才移除原快照，focused window 不存在时只回退到系统明确标识的 main window。
- 本机会话直接 AppKit miniaturize/performMiniaturize 也未改变独立合成窗口状态。最小化实际成功仍待复验；插件正确返回失败，未将请求接受冒充操作成功。
- 原生停止回调失败时继续释放其余资源，汇总异常；同一实例去重、重复停止幂等。
- Windows CI 的默认 cp1252 不能解码中文测试输出。明确父进程日志解码和 Python 子进程均使用 UTF-8，保留真实退出码及错误日志。
- 锁定 .NET SDK 10.0.403，统一旧 GBK 源文件为 UTF-8、打包依赖清单为 LF。入口 IL/资源/字符串相同但 MVID/COFF 时间戳随构建工具变化，打包时仅以完整内容生成这 20 字节的稳定身份，原始与打包哈希保留在清单。业务字节不改，公共文件仍全量比较。

```bash
python3 eng/m1.py build --clean
```

原生三端汇总在各目标系统分别 stage，再不带 --preview 汇总；必须来自同一提交、源码指纹、SDK 和相同公共输出。CI 默认不请求权限、不操作桌面、不伪造 Linux X11 会话。Mac 的 --desktop-read 是本机只读桌面回归开关；smoke-mac 会明确执行音量/合成壁纸/合成窗口验收，结束恢复。
