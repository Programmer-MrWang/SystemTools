# M6 平台与实体设备验收边界

本清单区分开发实现、当前环境可用性与实体设备验收。编译/CI 不代替硬件实际生效。唯一开发仓库为 SystemTools；ClassIsland 源码与安装应用保持原状。

| 子能力 | Windows x64 | Mac ARM64 | Linux x64 原生 X11 |
| --- | --- | --- | --- |
| 背后画面 | 保留既有 Windows 排除窗口链 | macOS 14+ ScreenCaptureKit 排除整个宿主进程，需屏幕录制权限 | 无可靠排除自身后端，明确不可用 |
| 背景明暗 | 保留原实现 | 实际组件区域、原生坐标转换、两帧稳定和迟滞、接管/恢复 | 因捕获前置能力不足而不可用 |
| OCR 避让 | 保留原实现 | Vision 中英文位置与置信度；两帧隐藏、三帧恢复；失败/停止恢复 | 因捕获前置能力不足而不可用 |
| 玻璃/材质 | 原 shader 与外观设置保留 | 自有浮窗/对话：26+ 原生玻璃，旧系统原生磨砂；系统辅助功能实时实色退路 | 未验证通用合成器模糊，实色退路 |
| 镜像/扩展 | 原显示切换行动 | 公共 CoreGraphics，至少两屏、确认及 15 秒回滚 | xrandr，至少两屏、正常旋转及单位变换、确认及回滚 |
| 仅内屏/外屏 | 原显示切换行动 | 无可靠公共关闭单屏 API，明确不可用 | xrandr，目标屏真实存在且可恢复时提供 |
| 内置背光 | 保留既有 WMI；未生效时明确失败 | 公共 IOKit 实际读写探测，当前设备没有可用后端 | 可写 sysfs，优先 actual_brightness 读回 |
| 外屏 DDC | 本轮未新增 Windows DDC 后端 | 可选已安装 m1ddc；显示器、端口与线路须支持 | 可选 ddcutil，须有 I²C 权限及显示器支持 |
| 软件变暗 | 不作硬件背光替代 | 不作硬件背光替代 | 不作硬件背光替代 |
| 设备启停/管理员重启 | 保留原实现，不在自动验收中执行 | 明确 Windows 专属，原配置保留 | 明确 Windows 专属，原配置保留 |

## 当前 Mac 已取得的证据

实际原版 ClassIsland 2.1.1.1 中，外部进程夹具的红色、黑色、白色与文字背景可在宿主绿色遮挡层之后被真实读取；确认排除宿主进程、Retina 像素尺寸与逻辑坐标转换。Vision 从未裁切的文本夹具返回置信度 1。自有 Avalonia 窗口安装原生系统材质、实际按钮点击、恢复经典表面通过。证据绑定包哈希，以最终收尾报告为准。

## 仍需对应环境的验收

- 双屏镜像/扩展、不同 DPI、负坐标排列、热插拔、应用/确认中断以及回滚失败反馈；当前 Mac 无第二屏。
- Mac 外屏 m1ddc/DDC 的具体显示器、端口与线缆真实读写；当前没有外屏或 m1ddc。公共 IOKit 无背光接口时保持不可用，不能勾选成功。
- Linux 实体 X11 桌面上的 xrandr、sysfs、ddcutil/I²C 和实际读回；复杂旋转、变换、平移明确拒绝。
- Windows 本轮包的真实桌面与设备回归；本机交叉编译及 CI 不替代实体设备。
- macOS 较旧运行版本的 NSVisualEffectView 外观、跨屏/Spaces、系统减少透明度/增强对比度实时切换的人工视觉检查。
- 主界面真实课表布局中的端到端隐藏/恢复、不同背景内容和长期性能/功耗；当前真实捕获/OCR 与判定链证据不等于所有布局的人工认可。

正式签名、公证、旧版升级/回退/卸载与发行继续属于 M7，本轮不发布。
