用户确认本轮先完成候选版与发行工具。代码、包和文档使用同一个发行策略；缺 Developer ID、公证、对应平台实机证据时只能输出 rc，不提升为 stable。正式身份及原功能 ID 保持，原维护标签/分支保留。

## M7.1：源码依赖与安全检查

按用户选择固定 Apache NPOI 源码、归档哈希及 SDK，自建 SystemTools.NPOI 2.8.1-source.1；保留原许可证和嵌入第三方许可证，并记录构建脚本哈希及唯一依赖补丁。新插件不消费上游 OSMF 二进制，不再间接引入旧 ImageSharp。背景/壁纸图片复用宿主 Skia 编解码并在解码分配前限制像素；Pkcs/Xml 固定到 10.0.15。

验证：干净 Release 构建通过，既有 M0—M6 回归通过；新增 7 项实际 XLS/XLSX 中文、公式、PNG 嵌图检查通过。实际解析的 115 个包实时公告扫描未发现漏洞；查询失败会中止，未把缺省成功当作审计。Mac 原生编译保留既有 AVCaptureDevice 弃用警告。

自审：源码和官方二进制条款分开，归档与补丁不符即拒绝；自建包来源随包保留。只提交本批依赖/图片处理及检查，升级快照和安装工具留待 M7.2。正式发布仍受平台验收和签名门禁限制。

新增正式身份启动前的旧预览冲突防护和版本快照。快照保存未知字段、密文与附件，同版本幂等、私有权限、总量限制、链接拒绝、源集合复核与坏备份拒绝。离线生命周期工具提供只读计划、验证包与备份、显式旧包停用、宿主停机检查、互斥、原子目录切换、验收后 seal、条件回滚及宿主标记式启停/卸载。

迁移 CLI 改为生成不可覆盖的审阅结果，再按原源/目标指纹应用；预览后变化拒绝，不在 apply 时悄悄重做预览。恢复既有迁移日志仍保留原契约。

验证：16 项 M7 .NET 检查、15 项离线安装/备份/回退测试、3 项实际迁移命令检查通过；完整插件 Release 构建通过。覆盖新装回退到不存在、旧包回退、备份损坏、配置变化保护、三种目录切换中断恢复、私有备份与可执行位。桌面启停和卸载留到 M7.5 用最终候选实测。

自审：回退前先校验全部备份与当前状态，才进行写入；中断日志中的预期状态先于目录移动落盘。seal 是用户对本次验收后配置的明确确认，之后新增数据阻止覆盖。恢复包与配置不删除；保留原迁移纠正和 IDE 修改。

### 跨端聚合自审纠正

第一轮 M7 依赖替换 CI 三端均编译/回归成功，但严格合包阻止了源码指纹不同的输出。新加入指纹的 NuGet.Config 和 NPOI 源码锁定 JSON 未指定 LF，Windows 检出自动 CRLF 导致差异；补齐明确换行规则，保持聚合校验不放宽。后续必须以新 CI 的严格合包结果为准。

## M7.3：Mac 候选签名与正式发行工具

新增 dry-run/preflight、ad-hoc 候选签名、Developer ID 逐项签名、Keychain profile 公证提交、Accepted 门槛、助手 stapling、团队/hardened runtime/Gatekeeper 验证与新包重封。操作范围只包含自己的库和采集助手，输入包不可覆盖。

验证：4 项发行工具契约测试通过；对明确记录哈希的 M6 工具夹具完成真实 ad-hoc 签名和全资产验证，未把夹具当作 M7 包验收。发现原 Vosk 自签验证不能通过，候选签名路径会重新签名自己的捆绑副本。真实 dry-run 明确拦截缺 Developer ID、团队及 notarytool profile。

自审：模拟输出只证明命令/门禁，不等于 Apple 接受；本机仅有 Apple Development，未执行正式签名或公证。后续 M7 最终包仍须重做自签、门禁和桌面生命周期验收；公开发行不自动执行。

### NPOI 跨系统编译顺序纠正

固定源码字节后，三端构建/回归仍成功，但合包进一步发现 NPOI.Core.dll 公共输出不同。Mac/Linux 相同，Windows 字符串集合与文件大小相同、元数据顺序不同；上游依赖默认 MSBuild glob 排序受系统大小写规则影响。构建器改为显式序号排序的 Compile 项，保留上游排除与外链项，包版本提升至 source.2 避免 NuGet 旧缓存。重建与 16 项 M7 检查通过；最终以新三端合包为准，不放宽公共字节校验。
