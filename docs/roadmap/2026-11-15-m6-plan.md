# M6 开发与验收顺序

基线：31f5beb，codex/cross-platform。仅修改 SystemTools 插件、自有原生桥和辅助应用。ClassIsland 源码、安装应用、SDK 10.0.403 锁及接手前 dirty 保留。

每批实现后进行相关检查、自审、中文约定式提交和代理推送，然后进入下一批。未具备的硬件和其他系统桌面验收保持待验，不将构建成功计作设备成功。

| 批次 | 交付 | 检查与退路 |
| --- | --- | --- |
| M6.0 | 契约、支持边界、宿主保护、批次记录 | 坐标/硬件分类/资源释放；记录宿主基线 |
| M6.1 | 真正排除本进程窗口的背景捕获 | Mac ScreenCaptureKit；区域、DPI、多屏边界、超时；Linux 无可靠后端时禁用 |
| M6.2 | 背景明暗驱动主界面主题 | 阈值、迟滞、稳定窗口、用户接管、停止恢复 |
| M6.3 | OCR 避让与恢复 | Mac Vision；置信度、命中区域、防抖；隐藏后持续采样，失败恢复 |
| M6.4 | 自有浮窗/对话的系统材质 | Mac 原生 NSGlassEffectView/NSVisualEffectView、透明叠层、命中和释放；辅助功能实色退路 |
| M6.5 | 显示器枚举和布局 | Mac 公共 CoreGraphics 与 Linux xrandr；读回、超时回滚、明确确认；不突破硬件数量限制 |
| M6.6 | 分类硬件亮度 | Linux sysfs/ddcutil；Mac 经实际可用性探测的后端；选择单设备、范围校验与读回；软件变暗不能充当背光 |
| M6.7 | 平台专属功能和菜单边界 | 保留 Windows 设备与提权功能；Mac/Linux 不冒充支持；新旧配置/ID/故障隔离 |
| M6.8 | 三端原生构建、合包、Mac 实际宿主验收和记录 | 同提交同源码、拒绝缺失/混源资产、宿主零改动、已验证与待验分开 |

权限仅从显式入口请求。背景帧与 OCR 仅驻留内存，不持久化桌面文本。系统材质不要求宿主用途声明或修改宿主源码。显示布局变更只在用户明确执行时进行，并默认限时回滚。设备启停、关机等不作为自动测试步骤。
